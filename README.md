## 🧠 Core Concepts

### Digital Logic

The projects explore fundamental digital logic concepts including:

* AND / OR / NOT gates
* XOR logic
* Multiplexers
* Decoders
* Encoders
* Combinational circuits
* Sequential circuits

These concepts form the foundation for designing more complex digital systems.

---

### Sequential Logic

The repository also focuses on circuits that depend on previous states.

Examples include:

* Counters
* Registers
* Clock-driven circuits
* State-based logic
* Frequency division

These concepts are essential for designing systems that operate synchronously with a clock.

---

### FPGA Implementation

Unlike software programs that execute sequentially on a processor, FPGA designs describe hardware behavior that can operate in parallel.

The general development process is:

```text
Digital Logic Design
        ↓
HDL Implementation
        ↓
Simulation / Verification
        ↓
Synthesis
        ↓
Place & Route
        ↓
FPGA Programming
        ↓
Hardware Testing
```

## 🔌 Hardware Interaction

The FPGA projects demonstrate how digital logic can interact with physical hardware.

Typical input devices include:

* Push buttons
* Switches
* Clock signals

Typical output devices include:

* LEDs
* 7-Segment displays
* Digital indicators

Example system flow:

```text
        Input
    Switch / Button
          │
          ▼
   ┌─────────────┐
   │     FPGA    │
   │             │
   │ Digital     │
   │ Logic       │
   └─────────────┘
          │
          ▼
        Output
     LED / Display
```
